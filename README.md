# 随手账本

一个没有预置用户数据的移动端记账 PWA。初始收支、债务和截图为空，账户余额、预算与预留金额为零。

## 功能

- 收入与支出记录，按日期查看时间轴及分类项目
- 债务明细板块（初始为空）
- 每日收支曲线、消费习惯、开销优化试算
- 中文订单截图识别、附件回看与备份导出
- 银行卡、微信余额修正，对账调整不算收支
- 私有云端同步、多设备合并、离线暂存与补传
- 可安装到手机主屏幕的 PWA

## 构建

```sh
npm ci
npm run build
```

页面源文件位于 `dist/`，构建输出为 `dist/client/` 和 `dist/server/index.js`。服务端使用 Cloudflare Workers 兼容接口、D1（`DB`）和 R2（`BUCKET`）。`drizzle/` 包含数据库迁移。

部署需配置平台提供的用户身份认证。服务端只信任部署平台注入的 `oai-authenticated-user-id`；不要直接将可由公网伪造此请求头的 Worker 暴露为生产服务。Sites 私有部署提供此认证边界。其他部署平台需自行替换认证适配。

云端账本与截图按用户隔离。浏览器保留离线缓存；不要在公用设备上保存个人账目。OCR 在设备本地执行，保存后的截图随账目上传。

## 数据与隐私

仓库不包含账目、账户标识、账单截图、登录凭据、个人预算或原项目的 Git 历史。供应商 OCR 运行文件及语言模型属于通用依赖。预览部署的项目配置不应作为另一部署的身份配置复用；新部署需要独立资源。

这是账本软件，不执行银行扣款或投资交易。扫码和截图识别结果需要核对付款账户与金额。
